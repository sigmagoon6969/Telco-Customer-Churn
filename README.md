Telco Customer Churn Analysis

This project analyzes customer churn in a telecom dataset using Python, MySQL, and Power BI. The goal was to identify churn drivers, measure revenue loss, and provide actionable retention recommendations.

Tools Used
Python (Pandas, Data Cleaning, EDA)
MySQL (Data Analysis)
Power BI (Dashboard & Visualization)
Dataset
7,043 customer records
34 features covering demographics, services, billing, contracts, and churn information
Key Work
Cleaned and prepared data using Python
Loaded processed data into MySQL
Performed churn and revenue-loss analysis with SQL
Built an interactive Power BI dashboard
Generated business recommendations to improve customer retention
Key Findings
Customer churn rate: 26.54%
Estimated annual revenue loss: $1.67M
Month-to-month contracts had the highest churn rate
Fiber optic customers showed higher churn behavior
Electronic check users were more likely to leave
Many customers churned within their first year
Outcome

The project highlights customer segments at the highest risk of churn and provides data-driven recommendations to reduce revenue loss and improve retention.
